# jwt-authentication

JWT-based authentication system built with Node.js and Express, including user login, token generation, and protected routes.


**Primary language:** JavaScript

## Project structure

Top-level files in this repository:

- `authServer.js`
- `jsonauthentication.code-workspace`
- `node_modules`
- `package-lock.json`
- `package.json`
- `request.rest`
- `server.js`
